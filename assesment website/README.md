# SkillTrack — Student Skill Development Management System

A front-end prototype for the CSA4305 Internet Programming assignment.

## Features
- Student skill profile and categorized proficiency levels
- Competency-gap identification
- Self/test-based assessment dashboard
- Project and certification evidence tracking
- Learning-plan recommendations
- Progress monitoring
- Mentor feedback
- Notifications/toasts and responsive navigation
- Light/dark theme
- Add-skill interaction
- XML data model and XSLT transformation example

## Run
Open `index.html` in a browser.

## Course mapping
- CSS: responsive layout, cards, navigation and visual styling
- JavaScript: navigation, modal, skill creation, notifications and theme toggle
- XML: `data.xml` stores sample structured skill information
- XSLT: `transform.xsl` demonstrates XML-to-HTML transformation
- MVC/JSP: the current package is a client-side prototype; JSP/Servlet/database integration can be added for the full server-side implementation.
